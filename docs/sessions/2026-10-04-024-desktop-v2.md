# 024 — Dashboard v2: one exe, a client-first design, Generate on request

Date: 2026-10-04 · Branch `feat/desktop-v2` · Owner request, 10:00 IST: "make the dashboard much better… a .exe to run, no setup files, no manual entering of stuff… annotation, target mask and video not generated automatically; a button chooses the captures and generates these on request."

## Owner decisions (2026-10-04)
- **Masks:** the game keeps recording them during every capture, because they can only be measured at render time. The dashboard keeps them in a hidden folder inside the session and releases them only on Generate.
- **Generate offers:** Video (MP4), Target masks, Labelled preview images. annotation.json (and labels.jsonl) stay automatic with every capture.
- **The Tauri exe** was shelved at m27 only for timing; there was no compatibility problem.

## Constraints
- Plugin is release-frozen (`release/2026-10-05`). The dashboard works against the existing WS protocol and the files the plugin already writes. No plugin change.
- Source carries no comments (repo convention).
- The client needs nothing installed beyond Windows 10/11, which includes WebView2 and Media Foundation.

## Shape
- `src-tauri` becomes a lib plus a bin. Modules:
  - `settings` — captures root (default `Documents\AnomalyCaptures`), first-run time, manual connection override.
  - `discovery` — finds the process listening on 127.0.0.1:8077, maps it to its UE log (editor: `<uproject dir>\Saved\Logs\<name>.log`; packaged: `<project>\Saved\Logs`), and reads the last `Control server token:` line.
  - `sessions` — scans the captures root, reports per-session metadata, and finalizes finished sessions. Finalizing waits until the capture has fully settled, then moves `target_mask\` and `mask_map.json` into a hidden `.pending\` folder inside the session.
  - `video` — Media Foundation H.264 MP4 encoder fed NV12 converted in-process. Even-dimension padding at bottom-right, as before. Index-aligned: a missing frame repeats the previous one and is counted.
  - `overlay` — a Rust port of `verify_capture.py`'s overlay inspector (RED = in annotation.json; AMBER = candidate only, with its tag). Writes only frames that carry a box, as `annotated\frame_NNNNN_annotated.png`.
  - `generate` — runs the requested outputs per session and emits progress events.
- The frontend keeps the transport and store and replaces the console layout with three screens: Capture, Library and Settings.

## Frontend design
- **Shell:** a dark ink rail with the brand mark, three nav items, and a connection block at the bottom (Connected / Recording / Looking for the game, plus the project name and kind). The content sits on a light neutral ground, and the game picture is the only saturated area.
- **Capture:**
  - The live view hugs the frame's aspect ratio. Active anomalies are boxed in their anomaly colour with a name tag. In "One object" mode the objects are outlined, and clicking one picks it as the target.
  - While recording, the view is covered with a calm paused state that says why ("Click into the game window to begin" until the focus gate opens).
  - The right panel holds: what to capture (Random mix with per-anomaly switches, or One object with anomaly chips and a target card); length presets; save folder; Advanced (format, saved size, seed, target distance, minimum object size, reset, developer HUDs); and a sticky Start button with a one-line blocker reason.
  - The recording state has a big frame counter, an elapsed clock, the capture tape and the fired-anomaly chips.
- **Signature move: the anomaly tape.** Each capture is drawn as a strip across its frames, with every event in its anomaly's colour. It is the same element in the Library rows and in the live recording panel.
- **Library:**
  - Rows show a thumbnail (the middle of the first labelled event), when, length, frames, resolution, anomaly count, the tape, and per-type counts.
  - Output badges per row: green = generated (click to open); dashed = ready to generate.
  - A row menu has Open folder and Move to Recycle Bin (two-step confirm). Rows still finishing show "Finishing up…".
  - Selecting rows raises a dark Generate bar with Video / Target masks / Labelled previews toggles. Progress shows inline per row.
- **Copy:** plain client language ("access key", "Happening now", "Saves to"). Nothing has to be typed. Manual connection is only under Settings.
- **Dev:** `npm run dev` without Tauri runs a mock game and a mock backend (`src/mock`, dev-only by `import.meta.env.DEV`). `?offline` / `?offline&editor` show the not-connected states.
